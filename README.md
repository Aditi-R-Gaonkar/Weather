# 🌦️ Weather App

A simple and responsive weather application that allows users to search for any city and view its current weather conditions in real time. The application fetches live weather data from a weather API and presents it through a clean, user-friendly interface.

## Features

- Search weather by city name
- View current temperature
- Display weather conditions
- View humidity and wind speed
- Dynamic weather icons
- Responsive design for different screen sizes

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Weather API

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Aditi691/Weather.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Weather
   ```

3. Open `index.html` in your preferred web browser.
